## Money rules (on top of CLAUDE.md)
- Paise integers everywhere. One shared `parseRupees(text) → paise | error` (string math: digits, optional `.dd`,
  commas and `₹` allowed; reject 3+ decimals, negatives, empty) and one `formatPaise`. Unit-test both hard.
- Every money mutation gets ONE operation id per user action via `OperationTracker` (kept on UNKNOWN / NETWORK /
  TEMPORARILY_UNAVAILABLE, renewed only on success or a definite refusal). A collection form that failed with a network
  error must show "Not confirmed — check the statement before trying again" and retry with the **same** id.
- **Unknown is never ₹0.** A statement/dues query that failed or is loading shows that state, never "₹0 due" or "Paid".
  "No price configured" ≠ ₹0 price. A pending cheque is shown as pending, never as paid.
- After any money mutation, invalidate the student's statement, dues, day book and cheque queries.

## Build
### 1. Fee setup (`src/features/fees/setup/`) — read `get_fee_setup(year)`; edit with `fees.manage`
- **Fee heads**: `save_fee_head` (name, code, kind regular/late fee/other — kind can't change after creation —, optional
  flag, active/retired). DUPLICATE → "code already used". Retired heads stay visible in history.
- **Receiving accounts**: `save_receiving_account(p jsonb)` — cash desk / bank (bank name, last 4, IFSC) / UPI (UPI ID).
  On edit send only changed keys; an empty string clears a field.
- **Terms**: `save_fee_term(year, name, order, due date, id, version, status)`; retire = `status:'retired'`. Show
  `invoices_issued` and the returned `note` (issued invoices keep their due date).
- **Price list** grid: classes × heads for one term → `save_fee_structure(term, class, lines)`. An empty cell means
  **"No price"** (head left out), visibly different from `₹0`. Show `invoices_already_issued` / `note` after saving.
- **Concession presets**: `save_concession_preset` (fixed ₹ or % — store basis points, 1% = 100 — and the heads it applies to).
- **Late-fee rule** for the year: `save_late_fee_rule` / `retire_late_fee_rule`.
- **Optional fees** (e.g. transport): head + section → `list_optional_fee_roster` → checkboxes → `set_optional_fees`
  (one operation id per save; send only changed rows).

### 2. Concessions for students — `list_student_concessions`, `grant_concession(op id, …)`, `revoke_concession`
Grant from the student fee page or a list. After granting, if `issued_invoices_not_changed` is non-empty show:
"Already-issued invoices aren't changed: INV/… — add an adjustment if needed" with a link to each invoice.

### 3. Invoicing (`src/features/fees/invoices/`)
- **Issue term invoices**: term (+ optional section) → `preview_term_invoices` (per student: lines, gross, concession,
  net, missing prices, conflicts) → confirm → `issue_term_invoices(op id, …)`. Show `issued`, `already_existing` and the
  **skipped list with names and reasons** (missing price, concession conflict) — never hide skipped students.
- **Opening balance** (single): `issue_opening_balance(student, year, head, amount, what it's for, reference, due date?)`
  — reference required (old ledger page/number); same reference + different amount → DUPLICATE (show it).
- **Opening balances import**: reuse the M1b import wizard with dataset `opening_balances` (columns from
  `get_import_template`; amounts are rupee text). Show `amount_totals.ready_paise` before confirming and
  `created_paise` after. Rows that match an existing balance are "Already exists"; same key with a different amount needs
  fixing.
- **Invoice actions** (from the statement): `add_invoice_adjustment(op id, …)` (charge/discount with reason),
  `waive_late_fee`, `cancel_invoice(op id, invoice, reason)` — only when nothing is paid and no pending cheque (the server
  says why otherwise). Admin/Accountant "Apply late fees" button → `evaluate_late_fees(today)`; show added / skipped
  (pending cheque) counts.

### 4. Collect payment (`src/features/fees/collect/`) — the accountant's main screen; must be fast and correct
- Find student (name / admission no) → `get_student_statement` → open invoices with balance.
- Method: cash · UPI · bank transfer · cheque. Amount (rupees) → allocate: default oldest due first, editable per invoice;
  **allocations must add up exactly** before Save is enabled; can't exceed an invoice's balance. Siblings are separate
  students — no cross-student allocation.
- Cash/UPI/bank → `post_collection(op id, …)`; UPI/bank need the receiving account + transaction reference. DUPLICATE
  reference → show the existing receipt number from `details`. Replay (`replayed: true`) → show the same receipt.
- Cheque → `record_cheque(op id, …)` (pending; does **not** reduce dues).
- Money above the dues: don't allow it; offer "Record the extra as a payment exception" → `record_payment_exception`.
- Success → receipt view.

### 5. Receipts — `get_receipt(receipt_id)`
Printable from the **snapshot only** (school, receipt no, date, student, class, method, reference, allocations, amount,
collector). Print CSS for A5/A4; amount in words (Indian numbering). Reversals listed under the receipt. Reprint always
shows the original content. Parent/student can open receipts of their own child.

### 6. Student fee statement (staff + `child.view`)
`get_student_statement`: invoices (Unpaid / Partial / Paid / Cancelled, Overdue flag; lines, concessions, adjustments),
payments with **where each went** (`allocations`), reversals, pending and bounced cheques, total due, open exceptions.
Parent area: same, read-only, for the selected child.

### 7. Corrections — `fees.manage`
- **Reverse a collection** (full or partial, reason): `reverse_collection(op id, collection, reason, amount?)`; show
  "still reversible".
- **Cheques register**: `list_cheques(status, from, to, cursor)` → clear (`clear_cheque`, optional changed allocations),
  bounce (`bounce_cheque`, reason), cancel a pending one (`cancel_cheque`, with version).
- **Payment exceptions**: `list_payment_exceptions(status)` → `resolve_payment_exception(id, note, version)`.

### 8. Reports (`fees.read`)
- **Day book**: `list_collections(from, to, method?, account?, collector?, search?, cursor)` — search by receipt no,
  admission no, transaction ref or name start. Totals for the shown range from `get_collection_report`.
- **Collection report**: `get_collection_report(from, to)` — by day/method, collector, account; posted vs reversed;
  pending/bounced cheques; concessions and waivers.
- **Dues**: `get_dues_report(year, class?, section?, only_overdue?, term?, only_with_balance?)` — students without a
  current class appear with "Class not set". Totals row must equal the sum of rows.
- CSV export of the day book and dues (client-side from the RPC rows; amounts as rupees with 2 decimals).
