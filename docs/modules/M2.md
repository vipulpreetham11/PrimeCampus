## Build
### 1. Timetable (`src/features/timetable/`) — `timetable.read_all` to view, `timetable.manage` to edit
- Section picker → `list_timetable_versions(section)` (draft / active / retired, effective dates).
- **Grid editor**: weekdays from `get_timetable_version().weekdays` × period slots (breaks shown, not editable). Each cell:
  subject (from the class's subjects — warn, don't block, on `subjects_not_in_class`) + teacher (optional; empty =
  visibly "Unassigned", never a holiday). Save with `save_timetable_draft(..., p_version_id, p_expected_version)`;
  show `conflicts` (teacher double-booked) inline per cell and `unassigned_periods`. CONFLICT → reload.
- Actions: **Activate** (`activate_timetable`; blocked while conflicts exist — show them), **Copy to another section**
  (`copy_timetable`, keep-teachers toggle), **Discard draft** (`discard_timetable_draft`, confirm).
- After activating, prompt: "Update lessons for the coming weeks" → `generate_lesson_sessions(from, to ≤63 days,
  section)`. Show `created / updated / cancelled_unused`, and list `kept_used` lessons ("already have attendance,
  diary or homework — not changed").
- Admin "Lessons" tool: generate for a date range (≤63 days), all sections or one.

### 2. Day & week schedule (`src/features/schedule/`)
- **Date view** (`get_date_schedule`) and **week view** (`get_schedule_range`, ≤7 days) for a section or a teacher.
  Show planned vs actual teacher, "Substitute" badge, cancelled lessons with reason, "planned teacher absent / half
  day" flags, diary/homework indicators.
- Lesson actions (`timetable.manage`): cancel (reason required), restore, change subject (only subjects of the class;
  server refuses if the lesson already has attendance/diary/homework — show its message) via
  `update_lesson_session` with `p_expected_version`.
- **Substitutions**: from a lesson → `suggest_substitutes` (availability present/absent/half-day/unmarked, conflict,
  teaches-this-subject) → `assign_substitute` (CONFLICT asks for an override reason and re-submits) /
  `remove_substitute`. History page: `list_substitutions(from, to, staff?)`.
- Parent/student see the same week view for their child (server scopes it).

### 3. Teacher "Today" (`src/features/teacher/`) — `lessons.teach`
`get_teacher_today(date)`: my lessons (with substitutions), each with marked/eligible counts, diary and homework state,
and my class-teacher sections with daily marked/eligible. Each lesson links to: mark attendance, write diary, set
homework. This is the teacher's home screen; must be excellent at 375px.

### 4. Student attendance (`src/features/attendance/`)
- **Marking roster** (`get_marking_roster` kind daily|period): fast keyboard/touch roster, "Mark all present", then
  change exceptions; P / L / A (+ H for daily). Save with `mark_student_attendance` — one operation id per save
  action, `expected_version` per student from the roster (null for unmarked). Show `conflicts` per student (someone
  else changed it — show their value and let the teacher re-apply), `unmarked_remaining`. Respect `can_mark`,
  `mode_on_date` (daily vs period), cancelled lessons, non-working days, future dates (server refuses — show message).
  **Unmarked is its own state** — never shown as present/absent.
- **Overview** (`get_attendance_overview(date)`, `attendance.summary`): per-section marked vs expected, present count;
  link to the roster for admins.
- **Student attendance** on the student profile and in the parent/student area: summary
  (`get_student_attendance_summary`: show "provisional" when `is_final` is false, coverage %) and per-day / per-lesson
  records (`get_student_attendance_records`, ≤63 days per call, paged by month).

### 5. Staff attendance (`src/features/staff-attendance/`) — `staff_attendance.read` / `.manage`
`get_staff_attendance(date, group?)` roster with staff-calendar day type and paid leave; mark with
`mark_staff_attendance` (one operation id per save, expected_version per row, conflicts shown). Read-only when
`can_mark` is false; future dates read-only.

### 6. Diary (`src/features/diary/`)
- From a lesson: `get_diary_entry` → edit with `save_diary_entry(body, expected_version)` (create = null version).
  `can_edit` decides the editor. CONFLICT → reload and show the newer text.
- Lists: `list_diary_entries(from, to ≤63 days, section?, staff?, only_missing?, cursor)` — teacher defaults to own
  lessons; admin/principal can filter by section/teacher; "Missing diary" filter.
- Parent/student feed: `get_student_diary(child, from, to)`.

### 7. Homework (`src/features/homework/`)
- Create from a lesson: `save_homework(null, lesson, due_on, description)`; edit/cancel with version.
- List: `list_homework(from, to, section?, subject?, staff?, status, cursor)` with progress (eligible / checked /
  completed / not completed / correction required); `can_edit`, `can_check` flags.
- **Checking roster**: `get_homework_roster` → `mark_homework_checks(operation id, observed_on, checks)` with
  completed / not completed, correction none/required/done, optional completed_on (≤ observed date) and comment.
  **Unchecked is its own state** (never "not completed"). Conflicts shown per student.
- Parent/student: `get_student_homework(child, from, to ≤400 days)` — show state, correction, completed late /
  observed late flags, teacher.

### 8. Parent / student area (`child.view`)
Home for the selected child: today's/this week's timetable, attendance summary + recent records, latest diary notes,
homework due/overdue. Uses only the child RPCs above; switching child (M0) clears everything.

## Rules
- All CLAUDE.md rules; operation ids via `OperationTracker` (one per save action, kept on uncertain errors, renewed on
  success/definite refusal); versions on every edit; CONFLICT reload paths.
- Rosters must work offline-gracefully: a failed save keeps the teacher's unsaved marks on screen with "Not saved —
  retry" (same operation id); never silently drop marks. No browser storage.
- Dates are school-local `YYYY-MM-DD`; week ranges computed with `dates.ts`.
- Keyboard: roster rows navigable with arrows, P/A/L keys; touch targets ≥44px at 375px.
