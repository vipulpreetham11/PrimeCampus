# M2 — Timetable, attendance, diary & homework: module report

Branch: `module/m2-academic` · Date: 18 Oct 2026 · Brief: `docs/modules/M2.md`

## Summary

M2 adds the academic day on top of M1 + M1b:

- **Timetable** (`src/features/timetable/`): versions per section (draft / active / retired with dates), new draft
  (blank or a copy of the current timetable), grid editor (weekdays from the server × bell-schedule slots, breaks
  shown read-only, "No lesson" / "Unassigned" / "Not a class subject", teacher clashes in the cell), version-checked
  save, Activate (blocked while clashes exist), Copy to another section (keep-teachers switch), Discard draft, and
  "Update lessons for the coming weeks" after activation. Admin **Update lessons** tool (≤ 63 days, one section or
  all).
- **Schedule** (`src/features/schedule/`): day and week views for a section or a teacher; planned vs actual teacher,
  Substitute badge, cancelled lessons with their reason, "Planned teacher absent / on half day", diary/homework
  state. Lesson actions (cancel with reason, restore, change subject) with the lesson version; substitute
  suggestions (availability, clash, teaches this subject) → assign (CONFLICT asks for an override reason and
  re-submits) / remove; substitution history.
- **Teacher "Today"** (`src/features/teacher/`): the teacher's home (Dashboard for `lessons.teach`): lessons of the
  day with attendance / diary / homework state, class-teacher day registers, homework to check; date navigation.
- **Student attendance** (`src/features/attendance/`): marking roster (daily or period), overview per section, and a
  student attendance panel (summary "Provisional" + coverage, records paged by month) on the student profile and in
  the parent area.
- **Staff attendance** (`src/features/staff-attendance/`): register per date / staff group with the staff-calendar
  day and paid leave; read-only without `staff_attendance.manage` and for future dates.
- **Diary** (`src/features/diary/`): lesson page (attendance link, diary editor, the lesson's homework), diary list
  (≤ 63 days, section / teacher, "Missing diary only", keyset Load more).
- **Homework** (`src/features/homework/`): set from a lesson, edit / cancel with the version, list with progress
  (keyset), checking roster.
- **Parent / student area** (`src/features/child/`): Home for the selected child (homework due, latest diary notes,
  attendance, this week's timetable) plus Timetable / Homework / Attendance / Diary pages.

Shared pieces: `src/lib/roster.ts` (roster state model), `src/lib/use-roster-save.ts` (save loop with operation
ids), `src/components/shared/roster-ui.tsx` (choice buttons, row state badge, keyboard, save bar, leave guard).

No backend files were changed. M3 was not started. Nothing was merged.
